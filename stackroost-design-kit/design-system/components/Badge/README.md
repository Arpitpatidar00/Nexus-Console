Status pills: colour plus words, never colour alone.

Tones: `neutral`, `success`, `warning`, `danger`, `info`, `ember`. Pass `dot` for live states (Healthy, Starting, Stopped). shadcn: extend `badgeVariants` with these tones.

- Words come from the real state: "Healthy", "Starting", "Not connected", "2 issues". No "Boost" or alarm copy.
- `ember` is for "new" or "selected", never for a problem.
