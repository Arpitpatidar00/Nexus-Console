Line icons on a 24 px grid, 1.75 stroke, round caps and joins, drawn in `currentColor`.

- In the app use `lucide-react` (already a dependency); this set exists so previews need no package. Names map to lucide: `activity`, `server`, `plug`, `shield-plus`, `hard-drive`, `cpu`, `message-square`, `sliders-horizontal`, `terminal-square`, `container`, `database`, `globe`, `key-round`, `zap`, `sparkles`, `cloud`, `folder`, `list`, `menu`, `upload`.
- Sizes: 20 px in 44 px circles (rail, icon buttons), 18 px in rows and buttons, 16 px in menus and small buttons.
- Icon-only buttons always get an `aria-label`.
