A measured number with its label: the big-number style from the references, used honestly.

- Only for a real, current measurement that answers the question on screen (disk used, uptime, load). Never a decorative hero number.
- Optional underline `progress` (0–100) or a `spark` series. The dot `tone` matches the status the number implies.
- Numbers use tabular figures; units go in `unit`, smaller and muted.
