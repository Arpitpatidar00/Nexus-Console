The floating icon rail that replaces the wide sidebar: 44 px circles, the active one filled.

Active = `sidebar-primary` (ember on smoked, ink on frost) with the ember halo. Items get a tooltip on the right and `aria-current="page"`. A small ember dot (`badge`) means the module has something new for you.

- Order follows the module registry; Settings sits in the footer.
- The rail floats inside the window with 16 px margin; it is glass (`sidebar`, `blur-lg`).
