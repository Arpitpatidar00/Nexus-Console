A thin smoothed line for a trend, with an optional soft area and end marker.

Tones map to the chart tokens: `ember` (chart-1, the series the view is about), `ivory` (chart-2), `lime` (chart-3), `info` (chart-4).

- 1.75 px stroke, no axes. If someone needs to read exact values, use a chart with axes or a table instead.
- Always pass a `label` (it is the accessible name).
